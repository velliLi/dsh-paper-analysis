# 集成电路方向解读口径

分析 IC/微电子/EDA 论文时，**指标脱离条件就没有意义**。本文件规定报告里必须补齐的条件字段，以及各类论文的重点。

---

## 1. 指标必须带的条件

### 功耗 / 能耗
- 区分：**动态功耗 / 静态（漏电）功耗 / 总功耗**；三者不可混称"功耗"。
- 必带条件：工艺节点、电源电压 Vdd、频率、工艺角（TT/FF/SS）、温度、活动因子假设。
- 能效指标口径：`TOPS/W`、`GOPS/W`、`pJ/op`、`fJ/bit`（存储/互联）。注意分子分母是否含外围电路（ADC/DAC/缓冲/时钟树）——**只算阵列不算外设是最常见的夸大手法**。
- 若论文只给能量不给出处（仿真/实测/估算模型），记为 `证据等级：估算`。

### 时序 / 速度
- 区分：**关键路径延迟、最坏负裕量 WNS、总时延 TNS、吞吐、延迟（latency）**。
- 必带条件：频率、工艺角、是否含时钟树/布线寄生的 post-layout。
- "提速 X 倍"必须问：同频率下比延迟，还是同延迟下比频率？是否同面积？

### 面积
- 单位口径：`μm²` / `mm²` / 等效门数（GE）/ 晶体管数。**必须写明是核心面积还是含 IO/PAD/电源网络的总面积**。
- 对比面积时要同工艺节点；跨节点对比需归一化（并说明用了什么缩放模型），跨节点直接比面积是无效对比。

### 精度 / 质量
- 数字电路/量化：是否含量化损失？位宽？是否重训练？
- 模拟/混合：是否含失配（Monte Carlo）、噪声、PVT 覆盖范围与样本数。
- 学习型方法：训练/验证/测试划分是否泄漏；是否报告方差；是否多次随机种子。

### 流程阶段（决定证据等级）
| 阶段 | 可信度 | 报告里必须标注 |
|---|---|---|
| 流片实测 | 最高 | 测试芯片面积、测试条件、样本数、是否与仿真一致 |
| Post-layout 仿真（含寄生） | 高 | 提取工具与寄生模型（RC/SPEF）、工艺角 |
| Post-synthesis（门级） | 中 | 综合工具与库、时序约束 |
| RTL 仿真 / 算法级 | 低 | 是否含硬件开销模型 |
| 理想模型 / 仅理论界 | 最低 | 明确写"未考虑实现开销" |

**致命误读**：把 RTL 或算法级结果当作"硬件实现了 X 倍提升"。报告里凡出现此类跨级引用，必须在同一句里点明证据等级。

## 2. 按子方向的重点

### 数字电路 / 加速器
工艺节点与电压、数据流（weight-stationary / output-stationary）、阵列规模、片上存储层次与带宽、稀疏支持、外设开销（ADC/DAC/NoC）、编译/映射工具链、能否扩展到更大模型。

### 模拟 / 混合信号
拓扑与补偿方式、增益/带宽/相位裕量、噪声（输入参考噪声、THD）、失配处理（斩波、修调、校准）、PVT 与 Monte Carlo 覆盖、电源抑制比 PSRR、测试芯片与探针条件。**没有实测的模拟论文，结论都要降级。**

### 存储器 / 存内计算
单元器件类型与一致性、写/读裕量、耐久度 endurance、保持特性 retention、阵列级非理想（IR drop、sneak path）、外围电路占比、电导漂移与校准开销。

### EDA / 算法（设计自动化、优化、学习型方法）
基准集与版本（如 ISPD/ICCAD 竞赛集、EPFL、MCNC）、对照工具与版本号、运行时是否含编译/综合/训练时间、硬件平台（核数/内存/GPU）、可扩展性实验（规模曲线的斜率）、是否开源与可复现脚本、与商业工具对比的授权与配置说明。

### 器件 / 工艺
结构参数（尺寸、堆叠、材料）、制备流程、测量方法（I-V / C-V / 可靠性）、统计样本量、与仿真（TCAD）的一致性、与既有器件在**同口径**下的对比。

### 系统 / 应用
端到端指标（延迟、吞吐、精度）与分解验证（哪一部分贡献了多少）、丢帧/失败率、能耗实测口径（是否含冷却、供电转换）。

## 3. 术语对照与规范写法

| 中文 | 英文（报告中保留原词） |
|---|---|
| 关键路径延迟 | critical path delay |
| 最坏负裕量 | worst negative slack (WNS) |
| 布局后 | post-layout |
| 工艺角 | process corner (TT/FF/SS) |
| 等效门数 | equivalent gate count (GE) |
| 存内计算 | compute-in-memory (CIM) |
| 设计空间探索 | design space exploration (DSE) |
| 消融实验 | ablation study |
| 浮点运算 | floating-point operations (FLOPs) |
| 每次操作能量 | energy per operation (pJ/op) |

规范：
- 数字与单位之间空格，单位用国际符号：`12.4 pJ/op`、`1.1 V`、`28 nm`、`3.2 mm²`。
- 提升/降低写成"从 A 到 B（+x% / −y%）"，并注明相对谁的百分比（相对基线而非相对绝对值）。
- 跨工艺、跨电压的对比一律加"不可直接比较"的标注。
